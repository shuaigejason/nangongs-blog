为什么要装这个

一直想在本机跑一个能自己接管的 AI 工具，看了一圈最后选了 OpenClaw。

安装步骤

一、准备环境

先确认 Node 版本。这里 node -v 一定要在 22 以上，否则内置的模块用不了。

node -v
npm -v

二、下载

直接从 GitHub 拉，走代理会快很多。

踩过的坑

坑 现象 解法
路径带空格 启动脚本报错 用引号包起来
端口占用 服务起不来 换端口
编码问题 中文乱码 脚本写成纯 ASCII

这次总共花了大概两个小时，主要是第三个坑耗时间。
